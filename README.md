# LiveWave MVP (front-end prototype)

## Run it
- Open `index.html` in a browser, or upload it to a static hosting provider.
- It is responsive and includes category filters, stream preview modals, and a demo creator-interest form.

## Important limitations
This is a front-end prototype only. It does not provide real video streaming, authentication, database storage, chat, payment processing, payouts, or moderation backend. Do not collect real credentials or payment details with this version.

## Suggested next build
1. Create a GitHub repository and deploy to Cloudflare Pages.
2. Add Supabase Auth and database tables for profiles, streams, follows, reports, and audit logs.
3. Integrate LiveKit for real-time video after estimating streaming costs.
4. Ask payment providers for written approval for the exact creator platform model before enabling paid tips or subscriptions.
5. Implement moderator/admin access, reporting, blocking, rate limits, age-appropriate safety controls, privacy/terms, and secure payment webhooks before public launch.
